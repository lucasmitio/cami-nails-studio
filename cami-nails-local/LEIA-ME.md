# Comece aqui

1. Leia **TUTORIAL_DE_USO.txt**.
2. Execute **instalar_atalho.bat** para preparar o acesso pelo ícone.
3. Para retirar os testes, feche o sistema e execute **zerar_dados_teste.bat**. Ele faz backup e preserva conta, serviços e modelos.
4. Abra o ícone e use **Administração** para alterar e-mail e senha.

O pacote contém somente código e documentação, sem banco de dados ou credenciais. Para o GitHub, leia **docs/GITHUB_PASSO_A_PASSO.txt**. A visão técnica está em **README.md**.
